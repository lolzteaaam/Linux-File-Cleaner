# Linux File Cleaner

**Linux File Cleaner** — это простая GUI-утилита для Linux, написанная на Python.

Программа помогает анализировать файловую систему и быстро находить:
- большие файлы;
- пустые папки;
- использование диска;
- папки с временными файлами, которые могут занимать место.

Проект сделан как учебная Linux-утилита с графическим интерфейсом.

---

# Возможности

- Удобный графический интерфейс
- Поиск самых больших файлов в выбранной папке
- Поиск пустых папок
- Просмотр занятого и свободного места на диске
- Анализ папок `/tmp` и `~/.cache`
- Запуск без pip, venv и сложной установки

# Скачивание проекта

```bash
git clone https://github.com/lolzteaaam/linux-file-cleaner.git
```

```bash
cd linux-file-cleaner
```

Выдать права на запуск:

```bash

```

Запустить программу:

```bash
./linux-file-cleaner
```

---

# Как пользоваться

1. Запустить программу командой:

```bash
./linux-file-cleaner
```

2. Выбрать папку для анализа.

3. Нажать нужную кнопку:

- **Большие файлы** — показывает самые большие файлы.
- **Пустые папки** — ищет пустые директории.
- **Диск** — показывает свободное и занятое место.
- **Мусор** — показывает размер `/tmp` и `~/.cache`.
