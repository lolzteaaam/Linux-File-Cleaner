# Linux File Cleaner

**Linux File Cleaner** — это простая GUI-утилита для Linux, написанная на Python.

Программа помогает анализировать файловую систему и быстро находить:
- большие файлы;
- пустые папки;
- использование диска;
- папки с временными файлами, которые могут занимать место.

Проект сделан как учебная Linux-утилита с графическим интерфейсом.

---

# Возможности

- Удобный графический интерфейс
- Поиск самых больших файлов в выбранной папке
- Поиск пустых папок
- Просмотр занятого и свободного места на диске
- Анализ папок `/tmp` и `~/.cache`
- Запуск без pip, venv и сложной установки

# Как пользоваться

1. Запустить программу командой:

```bash
./linux-file-cleaner
```

2. Выбрать папку для анализа.

3. Нажать нужную кнопку:

- **Большие файлы** — показывает самые большие файлы.
- **Пустые папки** — ищет пустые директории.
- **Диск** — показывает свободное и занятое место.
- **Мусор** — показывает размер `/tmp` и `~/.cache`.

## Разбор кода по блокам

### Блок GUI

Графический интерфейс реализован с помощью Tkinter. В нем есть окно программы, поле выбора папки, кнопки запуска функций и поле вывода результата.

### Блок поиска больших файлов

Программа проходит по выбранной папке, получает размер каждого файла и сортирует файлы по размеру. После этого выводятся самые большие файлы.

### Блок проверки диска

Для проверки занятого и свободного места используется библиотека shutil. Она позволяет получить общий размер диска, занятое место и свободное место.

### Блок поиска пустых папок

Программа проходит по директориям и находит папки, в которых нет файлов и других папок.

### Блок анализа временных файлов

Программа проверяет размер папок `/tmp` и `~/.cache`. Эти папки часто содержат временные файлы и кэш.
